<h1 align="center">SwimMotiv [Age 14&U]</h1>

Motivational times, Power Points and age group championship (AGC) cuts for 14-and-under competitive swimmers — built for quick, easy use right at the pool deck.

**100% FREE, no catch!**

Enter one race time and instantly see:
- Your official USA Swimming **Power Point** score for the swim
- Which **Motivational level** the time achieves — B · BB · A · AA · AAA · AAAA
- How it compares with supported **Age Group Championship cuts**
- The **gap to your next** Power Point milestone, level, or cut
- A built-in **Standards Library** to browse and search time standards

SwimMotiv works entirely offline. No account, login, or internet connection is required.

## Install the APK (Xiaomi / Oppo / Huawei / Honor / any Android)

1. Open the download link above on your phone and download `SwimMotiv.apk`.
2. When prompted, allow your browser to "install unknown apps" for this one install.
3. Open the downloaded file and install.

**Signing note:** the GitHub APK is signed with our own key — always update it from
GitHub. It cannot install over a store version (and vice versa); if you switch
channels, uninstall the other version first.
